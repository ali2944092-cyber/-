تحويل مشروع نور الصلاة إلى APK باستخدام GitHub Actions من الهاتف

المحتويات:
- noor-prayer-source.zip: ملفات مشروعك الأصلية.
- .github/workflows/build-android.yml: ملف إعداد البناء السحابي.

الخطوات:
1) افتح github.com من متصفح الهاتف وسجّل الدخول أو أنشئ حساباً.
2) أنشئ مستودعاً جديداً (New repository)، مثلاً باسم noor-prayer-android، واجعله Private.
3) افتح المستودع واضغط Add file ثم Upload files، وارفع noor-prayer-source.zip من هذا المجلد.
4) أنشئ الملف التالي عبر Add file > Create new file، واكتب في خانة اسم الملف حرفياً:
   .github/workflows/build-android.yml
5) افتح ملف build-android.yml الموجود ضمن الحزمة، وانسخ محتواه كاملاً إلى GitHub، ثم Commit changes.
   (إذا لم تستطع فتح ملف YAML داخل الهاتف، فك ضغط حزمة البناء وانسخ الملف من مجلد .github/workflows.)
6) افتح تبويب Actions في المستودع، اختر Build Noor Prayer APK، واضغط Run workflow.
7) انتظر انتهاء البناء بنجاح، ثم افتح صفحة التشغيل التي انتهت، وانزل إلى Artifacts واضغط noor-prayer-debug-apk لتنزيل APK.
8) فك ضغط ملف artifact الذي نزل، ثم افتح app-debug.apk وثبّته بعد السماح بالتثبيت من هذا المصدر.

ملاحظات مهمة:
- هذا ينتج APK تجريبي (debug) للتثبيت والاختبار، وليس إصداراً جاهزاً للنشر في Google Play.
- للنشر، يجب إنشاء AAB موقّع (release)، والاحتفاظ بمفتاح التوقيع وكلمات مروره بأمان. لا تشاركها مع أي شخص.
- يجب اختبار التطبيق فعلياً، خصوصاً تنبيهات الأذان والخلفية، قبل النشر. هذا البناء وحده لا يضمن أن التنبيهات تعمل عندما يكون التطبيق مغلقاً.
- قد يفشل البناء إذا احتاج المشروع إلى تعديل أو إذا تغيرت إصدارات أدوات البناء؛ عندها افتح سجل الخطأ وأرسله للمساعدة.
